A make.fun entry for "The Best Advice I Ever Got": one sentence, up to 200 characters, about the best advice the writer ever received. The program (`main.ts`, Node 22 stdlib only) deterministically writes a single lived sentence to the output path — a specific moment, a named person, and advice that proved true long after the moment passed.

> At seventeen, after I lost the final 6-1, Grandad said I could sulk only after writing down one thing I did right — twenty years on, the notebook is full and the sulking never happened.

Run it with Node 22:

```sh
node main.ts /output/entry.txt
```
